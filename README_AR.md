# ALI CINEMA PLUS — نسخة أولية

## المزايا
- صفحة دخول تطلب كود تفعيل قبل عرض المكتبة.
- كل كود فريد ويُستخدم مرة واحدة فقط.
- طلب اشتراك يدوي من الزائر.
- لوحة إدارة لمراجعة الطلبات وإصدار كود بمدة صلاحية.
- إضافة الأفلام والحلقات بروابط MP4 أو HLS متوافقة مع المتصفح.

## التشغيل على الكمبيوتر
1. ثبّت Node.js إصدار 18 أو أحدث.
2. فك ضغط المشروع وافتح الطرفية داخل المجلد.
3. نفّذ `npm install`.
4. انسخ `.env.example` إلى `.env` وغيّر `SESSION_SECRET` و`ADMIN_PASSWORD`.
5. نفّذ `npm start`.
6. افتح `http://localhost:3000`، ولوحة الإدارة من `/admin.html`.

## طريقة الاشتراك
- الزائر يرسل اسمه ورقم التواصل.
- يظهر طلبه في لوحة الإدارة.
- الإدارة تتحقق من الدفع يدوياً ثم تضغط «موافقة وإصدار كود».
- ترسل الإدارة الكود الذي يظهر مرة واحدة للعميل. لا تحفظ قاعدة البيانات نص الكود بعد إصداره، لذلك انسخه قبل إغلاق الرسالة.

## قبل النشر العام — مهم
- استضف الموقع على خدمة تدعم Node.js وHTTPS، وأضف متغيرات البيئة من إعدادات الاستضافة.
- استخدم قاعدة بيانات دائمة ونسخاً احتياطية؛ ملف SQLite المحلي مناسب للتجربة وليس كل بيئات الاستضافة.
- غيّر كلمة مرور الإدارة والسر السري، ولا تستخدم القيم الافتراضية.
- أضف حماية إضافية لمحاولات تخمين الأكواد وتسجيل دخول الإدارة، ويفضّل تخزين الجلسات في مخزن دائم.
- اربط وسيلة التواصل وتعليمات الدفع الفعلية في `PAYMENT_INSTRUCTIONS`.
- لا تضف إلا فيديوهات تملك حقوق بثها أو لديك ترخيص بعرضها. هذا القالب لا يوفّر أفلاماً أو روابط بث جاهزة.
- روابط HLS قد لا تعمل مباشرة في كل المتصفحات؛ يمكن إضافة مشغل HLS مخصص في مرحلة لاحقة.

هذه نسخة تأسيسية قابلة للتطوير، وليست بعدُ خدمة إنتاجية مدققة أمنياً.
